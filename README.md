# Voltigo

Site du jeu de cartes et de bluff Voltigo, pour 3 à 6 joueurs.

- `index.html` : accueil et présentation du playtest.
- `voltigo.html` : règles, simulateur et exemple animé.
- `inscription.html` : inscription au playtest.
- `merci.html` : remerciement après envoi.

Site statique pour GitHub Pages, depuis la racine de la branche `main`.
Pour une prévisualisation locale, ouvrir `index.html` dans un navigateur.
